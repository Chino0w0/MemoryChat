# MemoryChat 方案规划（v1.0 精简定稿）

## 1. 产品定位与目标
MemoryChat 是一个**以个人记忆与跨会话上下文理解为核心的多模型 AI Chat 端**。对标 Gemini / ChatGPT 的个性化记忆体验，将用户画像、长期偏好与历史对话摘要保存在本地 SQLite 中，并通过**“自训记忆门控小模型 + 语义检索小模型 + 主对话大模型”**联动机制，在不浪费上下文 Token、不胡乱记废话的前提下，让任意接入的大模型都能持续了解用户，同时支持轻量 Agent 工具与 `SKILL.md` 插件扩展。

## 3. 核心业务闭环（单轮对话）
1. **发消息前（检索注入）**：用户选定模型并发送消息 → 本地 `bge-small-zh-v1.5` 小模型计算查询向量，从 SQLite 召回 Top-K 相关情景记忆与历史会话摘要，连同常驻核心画像拼入 System Prompt。
2. **对话生成中（Agent 与流式回复）**：主大模型按需调用工具或挂载已选 `SKILL.md`，通过 SSE 流式返回回复，并在前端标注本轮参考了哪几条个人记忆。
3. **对话完成后（小模型门控与异步沉淀）**：
   - 若当前会话步数超阈值，异步压缩早期对话更新 `Session Summary`；
   - 本轮用户原话送入自训小模型 `MemoryGate` 判别：日常闲聊直接跳过（0 Token 开销）；若包含个人画像/偏好/近期事项，触发大模型结构化提炼（`ADD / UPDATE / NONE`）写入 SQLite，前端实时弹出 `✨ 记忆已更新` 供用户核对或一键撤销。

## 4. 课设交付契合点（截止 2026-12-20）
- **大模型 + 小模型联动**：主对话大模型 + 自训 `MemoryGate` 分类小模型 + `bge-small-zh` 向量小模型协同。
- **公开数据集评测**：采用百度千言 `DuLeMon` 中文长期对话记忆数据集完成小模型训练与端到端对比分析。
- **用户交互调整模块**：可视化个人记忆面板、记忆手动编辑/置顶/禁用开关、无痕对话开关、多模型参数与 Skill 自由挂载。
- **代码体量精简可控**：单 Python 后端 + 轻量 React 前端，去除冗余中间件与胶水协议，核心业务代码控制在 **1,300～1,600 行**，结构清晰，便于 7–14 分钟录屏逐行讲解与现场抽检答辩。
